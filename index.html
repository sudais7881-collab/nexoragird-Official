Backend configuration

To make sign-in, order management, payment verification, VPS provisioning, and boosts genuinely work, configure:

  • Authentication provider (e.g. Supabase)
  • Secure backend API and database
  • Server provider credentials stored server-side
  • Payment verification workflow
  • Authorization rules for owner actions

Never paste private provider API keys into public HTML or GitHub.
